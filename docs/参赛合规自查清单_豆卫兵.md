## 汇总：当前待办

1. **❌ 立即补**：真实用户 / 专家反馈记录 ≥3 份（访谈或试用 + 时间 + 照片）。
2. **⚠️ 确认**：成员学籍 / 年龄 / 导师合规；往届奖项无重复申报。
3. **⚠️ 留档**：601 张数据来源与标注口径、实验记录（5 折 CV 复现脚本 + 结果）、AI 生成内容溯源说明。
4. **⚠️ 如实**：论文写「在投」不写「已录用」；生产环境说明为演示部署（IP+自签）。
5. **⚠️ 核实**：软著证书（如有）归属与编号；开源框架署名完整。
6. **⚠️ 材料**：PPT 用商用授权字体；演示截图全部自截。
