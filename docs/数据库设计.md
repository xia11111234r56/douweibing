# 数据库设计

> 回应 2026 计算机设计大赛评审意见第 4 条：文档里数据库设计未涉及。
> 开发环境 SQLite（backend/app.db），生产 MySQL（通过 `DATABASE_URL` 切换，SQLAlchemy 统一适配）。

## 1. ER 图（文本版）

```
users ────< operation_logs          hosts ────< diseases
                                              │
                   diseases >──────< disease_symptoms >────── symptoms
                   diseases ───────< treatments
                   pesticides >────< pesticide_diseases >──── diseases
                   diseases ───────< disease_env_rules
users ────< recognitions >────────── diseases
graph_nodes >──────< graph_edges >────── graph_nodes
spatial_data（独立：区域 × 年份 × 指标）
```

## 3. 索引与约束
- 唯一约束：users.username、hosts.name、diseases.name、symptoms.name、pesticides.name
- 常用索引：diseases.host_id、treatments.disease_id、recognitions.disease_id、recognitions.created_at、spatial_data(region_code, year)
- 外键约束：除空间数据外全部启用级联删除/级联可空

## 4. 迁移策略
- 开发期：`Base.metadata.create_all`（幂等）+ `python -m app.data.seed` 灌种子
- 生产/结项：切换 MySQL 后使用 Alembic 迁移（M1 接入）
