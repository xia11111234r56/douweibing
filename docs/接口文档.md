# 接口文档（豆卫兵 API）

> 回应 2026 计算机设计大赛评审意见第 4 条：文档里功能模块未涉及。
> 后端基于 FastAPI，交互式文档在服务运行后可访问：`/docs`（Swagger UI）。
> 本文档为人工维护版，与代码同步更新。

## 0. 基础信息

| 项 | 值 |
|---|---|
| 基础地址 | 生产 `https://api.douweibing.cn`（备案+HTTPS 后）；开发 `http://127.0.0.1:8000` |
| 数据格式 | `application/json` |
| 鉴权方式 | 注册/登录返回 `access_token`，请求头 `Authorization: Bearer <token>` |
| 图片传输 | `POST /api/recognize` 传 base64 字符串（小程序端先压缩后转 base64） |

**当前鉴权说明**：识别、检索、统计、图谱读取、GIS 为公开接口；病害增删改与图谱写操作、操作日志查询**需管理员（Bearer admin token）**，普通用户访问返回 `403`；注册接口强制 `role=user`，禁止自封管理员。

## 1. 健康检查

### GET /api/health
无参数。

```json
{ "status": "ok", "database": "ok", "model_ready": true, "version": "0.1.0" }
```

| 字段 | 说明 |
|---|---|
| status | ok / degraded（数据库不通时） |
| database | ok / error |
| model_ready | `models/classifier.onnx` 是否存在 |
| version | 后端版本 |

## 2. 用户认证

### POST /api/auth/register
| 字段 | 类型 | 说明 |
|---|---|---|
| username | string | 2-64 位 |
| password | string | 6-128 位 |

> 注册的账号角色固定为 `user`；管理员由种子数据（admin/admin123）或现有管理员创建，不可通过注册接口自封。

### GET /api/logs （需管理员）
| 参数 | 说明 |
|---|---|
| limit | 返回条数，默认 50，最大 200 |

操作日志（按时间倒序），记录病害增删改与图谱增改等管理操作。

### POST /api/auth/login
| 字段 | 类型 | 说明 |
|---|---|---|
| username | string | |
| password | string | |

两者都返回：
```json
{ "access_token": "eyJ...", "token_type": "bearer" }
```
登录失败返回 `401`。

### GET /api/users/me （需 Bearer）
```json
{ "id": 1, "username": "admin", "role": "admin" }
```

## 3. 图片识别（核心接口）

### POST /api/recognize
请求体：
| 字段 | 类型 | 说明 |
|---|---|---|
| image_base64 | string | base64 编码的叶片图（必须） |
| env | object? | 多模态环境模态，见下表 |

env 子字段（全部可空）：
| 字段 | 类型 | 说明 |
|---|---|---|
| growth_stage | string? | 生育期：苗期/分枝期/开花期/结荚期/成熟期 |
| weather | string? | 天气档位：晴热干燥/高温高湿/阴雨连绵/雨后天晴/低温 |
| planting | string? | 种植方式：露地/大棚 |
| lat / lon | number? | 拍摄地点经纬度（用于 WorldClim 气候回查） |

响应：
```json
{
  "code": 200,
  "disease_id": 3,
  "disease_name": "炭疽叶斑病",
  "disease_type": "真菌性",
  "severity": "中度",
  "severity_desc": "病斑面积占比约 15%，建议...",
  "confidence": 0.93,
  "candidates": [ { "disease_id": 3, "name": "炭疽叶斑病", "disease_type": "真菌性", "confidence": 0.93 } ],
  "treatments": [ { "severity_level": "中度", "method_type": "化学防治", "content": "..." } ],
  "env": { "weather": "高温高湿", "growth_stage": "开花期", "climate": { ... } }
}
```

错误码：
| 状态码 | 含义 |
|---|---|
| 400 | base64 解码失败 |
| 503 | 模型未就绪（`models/classifier.onnx` 缺失） |

处理链路：分类（MobileNetV3 ONNX）→ MobileSAM 病斑分割→严重度 → 环境模态+知识规则后验修正 → 防治建议 → 识别记录落库。

## 4. 病害知识 CRUD

> 增删改（POST/PUT/DELETE）需**管理员** Bearer token；普通用户返回 `403`。写操作会记录到操作日志。

### GET /api/diseases
全部病害（含寄主名与防治方案）。公开可读。

### GET /api/diseases/{id}
单条，不存在返回 404。公开可读。

### POST /api/diseases
| 字段 | 类型 | 说明 |
|---|---|---|
| name | string | 病害名（与模型标签一致） |
| disease_type | string | 真菌性/细菌性/病毒性/生理性/健康 |
| host_id | int | 寄主作物 id |
| name_en / pathogen / symptoms / conditions / image_path | string? | 可选 |

### PUT /api/diseases/{id}
局部更新，传哪些改哪些。

### DELETE /api/diseases/{id}
返回 `{ "ok": true }`。

病害统一返回结构（DiseaseOut）：
```json
{
  "id": 1, "name": "绿豆叶斑病", "name_en": null,
  "disease_type": "真菌性", "pathogen": "...", "symptoms": "...",
  "conditions": "...", "image_path": null,
  "host_id": 1, "host_name": "绿豆",
  "treatments": [ { "id": 1, "severity_level": "轻度", "method_type": "农业防治", "content": "..." } ]
}
```

## 5. 多维多条件检索（导师课题核心）

### GET /api/search
全部参数可空，多条件叠加过滤：
| 参数 | 说明 |
|---|---|
| keyword | 病害名/症状/病原/环境关键词模糊匹配 |
| host | 寄主作物名（如：绿豆） |
| disease_type | 真菌性/细菌性/病毒性/生理性 |
| pesticide | 药剂名关键词 |
| severity | 按某严重度有防治方案：轻/中/重 |

返回 `DiseaseOut[]`。

## 7. 知识图谱（动态知识图谱 · 图引擎抽象层）

图谱为**双后端图引擎**：SQL 三元组表（graph_nodes/graph_edges）为**唯一事实源**，生产/服务器默认；
Neo4j 真图数据库（本地演示/验证，跑原生 Cypher 图算法）只读只算 + 尽力镜像。
Neo4j 缺失/中途故障**自动回落 SQL**，接口契约不变；`GET /api/graph/engine` 透明暴露当前引擎与降级错误。

### GET /api/graph
返回整图（nodes + edges），ECharts graph 渲染：
```json
{ "nodes": [ { "id": 1, "label": "寄主", "name": "绿豆", "properties": null } ],
  "edges": [ { "id": 1, "source_id": 1, "target_id": 2, "relation": "感染", "weight": 1.0 } ] }
```
label 取值：`寄主 / 病害 / 症状 / 药剂 / 环境`；
relation 取值：`感染 / 表现为 / 防治 / 适宜 / 易混淆`（「易混淆」weight 累计纠错次数）。

### GET /api/graph/nodes/{label}
按标签取节点（如 `病害`、`药剂`、`寄主`）。

### POST /api/graph/nodes
| 字段 | 类型 | 说明 |
|---|---|---|
| label | string | 节点类别 |
| name | string | 节点名 |
| properties | object? | 附加属性 |

### POST /api/graph/edges
| 字段 | 类型 | 说明 |
|---|---|---|
| source_id / target_id | int | 两端节点 id（必须存在） |
| relation | string | 关系名 |
| weight | number | 默认 1.0 |

> 节点/关系新增（POST）需**管理员** Bearer token；写操作先落 SQL（事实源），成功后再尽力镜像 Neo4j（失败不致命）。

### GET /api/graph/engine
图引擎状态（降级透明暴露）：
```json
{ "engine": "neo4j", "node_count": 69, "edge_count": 93, "neo4j_error": null }
```
Neo4j 运行中返回 `engine="neo4j"`；缺失/中途故障回落 `engine="sql"` 且 `neo4j_error` 非空。

### GET /api/graph/path
防治路径推荐（图算法）：
| 参数 | 说明 |
|---|---|
| disease | 病害名（Mode B：病害 → 防治路径） |
| severity | 轻度/中度/重度（可选，决定防治药剂） |
| weather | 天气档位（可选，匹配「适宜」边追加环境段） |
| from_id + to_id | Mode A：任意两节点最短路径（无权，跳数最少） |
| max_hops | 最大跳数，默认 5，取值 1-8 |

响应：`{ engine, mode: "pair"|"disease", path[], steps[], highlight{node_ids,edge_ids}, note }`。
Mode A 在 SQL（networkx shortest_path）与 Neo4j（Cypher shortestPath）两引擎下结果一致。

### GET /api/graph/reason
可解释推理链：`disease`（必填）+ `severity` + `weather`（可选）。
返回 5 段链 `steps[]`：寄主→感染→病害；病害→表现为→症状（前 3）；病害→适宜→环境（weather 匹配）；
病害→防治→药剂（按严重度，药剂来自 treatments 方案文本）；外加 `summary` 结论 + `controls[]` 防治药剂 + `matched_symptoms[]`。
识别接口 `POST /api/recognize` 同源附带 `reasoning` 字段（同一推理链），供识别结果页直接展示。

> **动态性**：识别热度回写病害节点 `properties.heat`（Web 图谱按 heat 缩放节点大小）；
> 用户纠错自动沉淀「易混淆」边（weight 累计次数），图谱随使用生长。
> **种子同步**：`python -m app.data.sync_neo4j`（SQL → Neo4j 全量重建，db_id 为键幂等可重跑）。

## 8. GIS / 遥感

### GET /api/gis/mungbean?level=country&year=2023
| 参数 | 说明 |
|---|---|
| level | country（全球） / province（中国省级） |
| year | 指定年份，缺省返回最近一年 |

```json
{ "level": "country", "year": 2023,
  "series": { "production": [ { "name": "China", "value": 1200000 } ],
              "area": [ { "name": "China", "value": 800000 } ] } }
```
格式适配 ECharts map。

### GET /api/gis/geojson/{name}
读取地图底图（`data/spatial/geojson/{name}.geojson`），返回标准 GeoJSON。缺文件返回 404。

### GET /api/gis/risk
省级病害风险区划（WorldClim 7 月均温×降水规则模型预计算入库）：
```json
{
  "model": "climate-rule",
  "desc": "7月均温×降水 → 高温高湿适宜度 → 病害风险指数（WorldClim 2.1）",
  "series": { "risk_index": [ { "name": "内蒙古", "value": 18 } ] },
  "risk": [ { "name": "内蒙古", "value": 18, "level": "中" } ]
}
```
