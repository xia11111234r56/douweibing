# 功能模块文档

> 回应 2026 计算机设计大赛评审意见第 4 条：**文档里功能模块、数据库设计均未涉及**。

## 1. 系统定位

**基于多模态数据融合、动态知识图谱与 GAN 增强的绿豆病害智能分级与精准防治系统**：

- 面向农户/农技人员的**病害智能识别与精准防治**工具
- 面向数据管理人员的**杂豆病虫害数据管理与检索**平台（贴合导师课题）
- 三端统一：一套 FastAPI 后端，Web 平台为主，小程序薄端为辅

## 4. 关键用例

| 用例 | 前置条件 | 主流程 | 结果 |
|---|---|---|---|
| UC-1 拍照识病 | 用户登录/游客 | 上传叶片图 → 系统分类+严重度 → 环境模态融合 → 输出防治方案 | 病害/严重度/置信度/防治方案 |
| UC-2 病害检索 | — | 输入关键词或组合条件 → 列表返回 | 匹配病害及防治 |
| UC-3 图谱增改 | admin | 新增节点/边 | 图谱可视化即时更新 |
| UC-4 GIS 查询 | — | 选择国家/省/年份 → 地图渲染 | 种植分布/风险区划图 |

## 5. 与申请书承诺的映射

| 申请书承诺 | 本系统实现 |
|---|---|
| 光学图像识别 | MobileNetV3-Large 图像分类（真实训练，ONNX 导出 CPU 推理） |
| 严重程度智能分级 | 深度严重度模型（mobilenetv3 骨干特征 + 逻辑回归，179 张人工标注，5 折交叉验证一致率 0.844）；颜色形态学面积比路径实测 0.32 无法对齐主观图级标注，仅作模型缺失回退；阈值语义依据大豆灰斑病叶部病斑分级标准七级合并为健康/轻/中/重（轻=(0,6%]、中=(6%,25%]、重>25%） |
| 环境传感数据 | EXIF+WorldClim 气候回查 + 用户环境档位（近似，如实说明为近似而非传感器） |
| 用户操作记录 | 识别记录（含多模态上下文）落库 + 操作日志 |
| 动态知识图谱 | 双后端图引擎：SQL 三元组表（graph_nodes/graph_edges 事实源）+ ECharts 可视化 + 动态增改；本地 Neo4j 验证 Cypher 图算法（防治路径推荐 + 5 段可解释推理链）；识别 heat 回写 + 纠错易混淆边动态生长 |
| 数据增强 | ACGAN 生成 1000 张合成病害图；A/B 消融（0.7865→0.8202）+ 生产模型（GAN+真实虫食补充）已部署（重评估 test89 0.8315 / 178 张 0.8483） |
| AR 热力图（延伸） | P3 预留（叶部病斑热力可视化） |

## 6. 非功能需求

- **准确率**：分类 ≥85%，严重度分级 ≥80%（测试集真实指标，不编造；全量 5 折 CV pooled 0.8519±0.022 达标，固定 89 张生产集重评估 0.8315（多 seed mean 0.823±0.027）——评估协议与训练一致，0.83 为评估集过小的保守下限；小类样本稀缺是首要瓶颈；严重度 5 折交叉验证一致率 0.844）
- **性能**：单图识别 ≤3s（CPU 推理）
- **一致性**：同一图多次推理结果一致
- **可复现**：环境上下文（WorldClim 回查）确定性可复现
- **文档一致性**：本文档与实际代码实现严格同步（吸取上次教训）
