## 2. 种子文献（本次方案查证所得，相关工作起点）

### 多模态方法
- **CMAF-Net**：Cross-Modal Attention Fusion Network for Robust Pomegranate Disease Detection Using Visual and Micro-Climatic Data（IEEE，2025）。MobileNetV3 视觉特征 + 温湿度参数双流跨模态注意力融合，检测石榴病害（准确率 99.61%）。→ 支撑"图像+温湿度"多模态可行性。
- **AgriFusionNet**：A Context Aware Multimodal Leaf Disease Diagnosis and Classification（Frontiers in Fungal Biology，2026）。图像(EfficientNet-B0) + 症状文本(BERT) + 环境(MLP) 三模态，在"多模态增强 PlantVillage"上 98.94%。→ 三模态架构参考。
- **PlantFusion**：A Novel Multimodal Dataset and Hybrid Multimodal Deep Learning Framework（IEEE）。图像+文本+环境多模态植物病害数据集与混合模型。

### 绿豆病害基线
- **Inception V3 vs EfficientNet-B3**：mung bean Cercospora leaf spot（绿豆尾孢菌叶斑病）识别，InceptionV3 94.68%、EfficientNet-B3 93.24%，11 个品种田间验证 70–97.95%（Chilean Journal of Agricultural Research, 2025）。→ 绿豆病害小样本基线参考。

### 严重度 / 分割
- **SAM / MobileSAM**：Segment Anything（Kirillov et al., ICCV 2023）；MobileSAM（Zhang et al., 2023）轻量变体 ~40MB，可 CPU 推理。→ 零样本病斑分割方法依据。

### 数据集（论文中可作为数据来源引用）

- Mendeley: An Image Dataset of Seven Major Pulses Grown in Bangladesh（DOI 10.17632/skd9w9g5jm.1，~17.5k 图）
- Mendeley: Black Gram Leaf Image Dataset（DOI 10.17632/45djgf3p96.1，绿豆近缘）
- HuggingFace: Strawberry-MM-Straw5（图像+环境 CSV 多模态）
- Kaggle: PlantVillage
